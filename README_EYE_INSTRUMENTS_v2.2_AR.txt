إضافة قسم أجهزة العيون – الإصدار 2.2

هذه الحزمة تضيف القسم 13 (EINS) وموضوعاته الـ45 فقط. قسم البحث الموجود مسبقاً هو القسم 14 ولا يتم إنشاؤه أو تعديله.

خطوات التنفيذ:
1) ارفع محتويات هذا الأرشيف إلى مستودع GitHub مع الحفاظ على بنية المجلدات.
2) في Supabase SQL Editor نفّذ ملف SUPABASE_ADD_EYE_INSTRUMENTS_v2.2.sql مرة واحدة.
3) تحقق من ظهور EINS وعدد 45 موضوعاً.

الاستيراد آمن لإعادة التشغيل من ناحية عدم تكرار الأكواد. لا يتضمن محاضرات أو حذفاً أو تعديلاً لمحتوى الأقسام الأخرى.
