HAKIM OPTICS ACADEMY v2.1
========================

المحتويات
- index.html / styles.css / app.js: واجهة الأكاديمية.
- content/: ملف المحتوى المحلي الاحتياطي.
- assets/ و icons/: شعار الأكاديمية وأيقونات التطبيق.
- manifest.webmanifest / sw.js / offline.html: دعم PWA والتخزين المؤقت.
- SUPABASE_ACADEMY_SETUP.sql: تأسيس جداول الحسابات والدورات والاشتراكات والمراجع الاختيارية.

النشر على GitHub Pages
1) فك ضغط الحزمة.
2) افتح مجلد alhakim_v2 وارفع محتوياته إلى جذر المستودع (لا ترفع المجلد كطبقة إضافية).
3) تأكد أن index.html في الجذر.
4) من Settings > Pages اختر Branch: main و Folder: /(root).
5) بعد النشر افتح الموقع مرة مع اتصال إنترنت لتحديث ملفات PWA.

المحاضرات والمراجع
- تعرض المنصة المحاضرات المتوفرة في المحتوى المحلي، وتدمج المحاضرات التي تعيدها قاعدة Supabase.
- المسودات تظل موسومة بأنها قيد المراجعة العلمية.
- عند وجود رابط URL أو DOI للمرجع يفتح الرابط مباشرة. إذا كان المرجع مجرد عنوان، يفتح بحث Google Books عن العنوان، ولا يعني ذلك أن نسخة الكتاب متاحة مجاناً.

الحسابات والإدارة والدورات والاشتراكات
- تسجيل الدخول يستخدم Supabase Auth.
- شغّل ملف SUPABASE_ACADEMY_SETUP.sql من Supabase SQL Editor لإنشاء جداول الأكاديمية الاختيارية وسياسات RLS.
- أنشئ المستخدم الإداري من Supabase Authentication أولاً، ثم أضف UUID الحقيقي إلى academy_profiles واجعل role = admin باستخدام مثال SQL في آخر الملف.
- لا تمنح دور admin من واجهة عامة ولا تضع service_role key في ملفات الموقع.
- بعد ذلك يمكن قراءة الحساب والدورات والاشتراكات حسب سياسات RLS. واجهات v2.1 حالياً واجهات تأسيس/عرض؛ عمليات إنشاء وتعديل وحذف الدورات والاشتراكات والحسابات تحتاج استكمال لوحة CRUD آمنة قبل استخدامها تشغيلياً.

حدود الإصدار
- لا تتضمن هذه الحزمة بوابة دفع أو تسجيل ذاتي أو إدارة كاملة للطلاب/المحاضرين.
- لا تعتبر بيانات الاشتراك المدخلة يدوياً إثباتاً للدفع.
- يلزم اختبار صلاحيات Supabase وأسماء أعمدة جداول المنهج الفعلية بعد النشر.
- لا تضع مفاتيح سرية في GitHub. المفتاح الموجود في app.js هو publishable key فقط، ويجب أن تكون RLS مفعلة على الجداول.
