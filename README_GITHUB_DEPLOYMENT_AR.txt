HAKIM OPTICS ACADEMY v2.0 — حزمة الرفع إلى GitHub Pages

طريقة التثبيت:
1) فك ضغط الحزمة.
2) ارفع محتويات مجلد alhakim_v2 إلى جذر المستودع Alhakim-Optics-Academy، وليس المجلد نفسه.
3) تأكد من وجود index.html في جذر المستودع.
4) من Settings > Pages اختر Deploy from a branch ثم main و /(root).
5) انتظر اكتمال النشر، ثم افتح الموقع مع تحديث قوي للصفحة.

محتويات الحزمة:
- index.html و styles.css: الواجهة المتجاوبة.
- app.js: تحميل محلي احتياطي ومحاولة قراءة الجداول departments و topics و lessons من Supabase.
- content/: نسخة المحتوى المحلية الاحتياطية الحالية.
- assets/alhakim-logo.png و icons/: شعار الأكاديمية وأيقونات PWA.
- manifest.webmanifest و sw.js و offline.html: التثبيت والعمل دون اتصال.

اتصال Supabase:
تم ضبط عنوان المشروع ومفتاح Publishable المخصص للواجهة في app.js. هذا المفتاح ليس service_role. يجب أن تكون سياسات RLS في الجداول departments و topics و lessons تسمح بقراءة البيانات المنشورة للزوار. لا تضع service_role أو كلمات مرور في ملفات الواجهة.

مهم حول البيانات:
تحاول الواجهة قراءة الجداول الثلاثة من Supabase باستخدام select=* ثم تطبيع أسماء الحقول الشائعة. إذا فشل الاتصال أو منعت RLS القراءة، تنتقل تلقائياً إلى ملف JSON المحلي. نسخة JSON المرفقة أقدم من المنهج الحالي، وتحتوي 12 قسماً و231 موضوعاً؛ لذلك لا تعرض الأرقام الحالية 13/610 عند تعذر جلبها من قاعدة البيانات. يلزم اختبار أسماء الأعمدة الفعلية وسياسات RLS بعد النشر.

نطاق النسخة:
هذه حزمة واجهة تعليمية مع قراءة سحابية للمنهج عند نجاح صلاحيات القراءة، واحتياط محلي وتخزين تقدم الدروس محلياً. لا تتضمن بعد نظام حسابات طلاب، لوحة إدارة، صلاحيات محاضرين، اختبارات مركزية متزامنة، مدفوعات أو مزامنة تقدم بين الأجهزة. لا تعتبر الدروس مسودة معتمدة سريرياً؛ راجعها علمياً قبل النشر.

التحديث:
عند رفع إصدار جديد، يتغير CACHE_NAME في sw.js لتحديث التخزين المؤقت. إذا استمر ظهور إصدار قديم، أغلق التطبيق وافتحه مجدداً أو امسح بيانات الموقع من المتصفح.
