# Section 01 — Anatomy and Physiology: Illustration and Photograph Placement

All 45 published ANP lectures have one original, topic-specific SVG teaching schematic. The diagrams are original vector teaching aids, not diagnostic images and not manufacturer photographs. They are designed as two-panel concept maps: anatomical structures on the left and physiological relationships on the right.

## Rendering

Images are embedded in `public.lessons.content_en` using HTTPS Markdown image syntax and raw GitHub SVG URLs. The academy's existing Markdown image renderer and responsive lecture-image CSS were previously verified in `app.js` and `styles.css` during the Diagnostic Optometry section work.

## Editorial note

The current database audit confirms 45 illustration links and photographic references in 14 distinct lectures (16 photo placements). Final per-lecture visual placement and live-device rendering checks remain pending. The SVGs are conceptual teaching diagrams and must not be mistaken for clinical photographs or diagnostic scans.
