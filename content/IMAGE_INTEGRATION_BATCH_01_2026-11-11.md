## Integration note
The SVGs are stored as first-party original assets in the repository and are intended to be embedded at the corresponding explanatory point in each lecture, not collected at the end. The current lesson renderer must be checked for Markdown image support before adding image syntax to published lesson content; this batch deliberately does not alter lesson text or publication status.
