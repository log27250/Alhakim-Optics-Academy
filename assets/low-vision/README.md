# Low Vision — Embedded Teaching Illustrations

This first illustration batch is integrated into the published Low Vision lessons in HAKIM OPTICS ACADEMY.

## Assets
- `functional-vision-assessment.svg` — visual acuity, visual field and contrast as complementary assessment domains.
- `low-vision-optical-aids.svg` — hand magnifier, stand magnifier and electronic magnifier.
- `critical-print-size.svg` — reading print-size progression and critical print size.

## Integration
- Assets are original SVG teaching diagrams stored in this repository.
- Lesson markdown references the SVGs using standard image syntax.
- The lesson renderer converts image syntax to responsive in-page images (no external browser navigation).
- Images are lazy-loaded and can be enlarged by tapping/clicking.
- Current integration: LV-001-L01 (2 illustrations), LV-011-L01 (1 illustration).

These are original educational diagrams, not photographs of specific commercial devices. Future batches may add licensed real device photographs with source attribution.
